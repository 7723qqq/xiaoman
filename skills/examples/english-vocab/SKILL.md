# 每日背单词 + 艾宾浩斯复习

触发：「背单词」「今日单词」「复习单词」「英语学习」。

1. 先调用 vocab_status 看偏好。stats.learned 为 0 且提醒还关着时视为第一次使用，问一句每天几个新词、几点提醒，再用 vocab_prefs 保存；提醒默认关闭，用户同意后再打开。
2. 要开始背单词时调用 vocab_today，以返回的日期、due_words、new_words 和 stats 为准；用户只问进度时停在 vocab_status，不要生成批次。不要自己算日期，也不要查记忆里的复习计划。
3. 有 due_words 时先复习：只列英文单词，让用户说中文意思；用户答完再逐词讲解。答完后用 vocab_grade 提交每个词的对错，只提交 due_words 里的词；用户说「直接看」时跳过提问，但讲完仍要提交结果。
4. 新词逐张卡讲，格式：
   **word** /音标/ 词性. 中文释义
   例：English sentence.
   译：中文翻译。
   搭：make progress 取得进步；in progress 进行中
   音标、搭配优先用工具里的数据；工具没给就按你的知识补，拿不准的省略，不要编造。释义已经带词性时不要再重复 pos。例句按专升本阅读、写作难度写。
5. 用户要改每天词量、提醒时间或开关提醒时用 vocab_prefs；词库里没有的词用 vocab_add_word 加入后再取一次 vocab_today。
6. 结束时用一句话报进度：今天复习了多少、学了多少、连续多少天、还剩多少词。

不能做：不替用户答题；不编造音标、搭配或例句出处；不自己改复习轮次。
