# 淘宝比价

目标：帮用户比一比价，最后停在最便宜那家的**商品详情页**。只看、不买。

1. 关键词取自用户的话（品牌、型号、规格都带上）；用户给了预算或「只看官方旗舰店」之类条件，一并记住。关键词太模糊（如只说「耳机」）时用 ask_user 问清楚。
2. 启动淘宝（com.taobao.taobao），点首页搜索框输入关键词并搜索。出现弹窗、广告、开屏页先关掉；出现滑块、验证码或要求登录时，用 ask_user 请用户本人处理，不要自己拖滑块。
3. 在搜索结果里看前 3 个**和关键词匹配**的商品（跳过「广告」标且明显不相关的），逐个记下：店铺名、标价（券后价有就写券后价）、销量（如「已售 1 万+」）。
4. 比较后选出最便宜的一家；价格相同时选销量高的。符合用户预算/条件的优先。
5. 点开这家的商品，停在商品详情页。不要点「加入购物车」「立即购买」「领券购买」，不要选规格进入下单页；页面上出现收货地址也不要展开。

finish 时 summary 用三行列出 3 家（店铺、价格、销量），再写一句「最便宜的是 X，已打开它的商品页」。看不到价格或结果不足 3 家时如实说明。
